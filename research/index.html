in progress · ALS beamline 7.3.3

Closing the loop on block copolymer inverse design

A team-built closed loop in which a Gaussian-process optimizer drives a synchrotron beamline directly, finding the processing route to a named target morphology in 20–30 experiments instead of thousands.

  • Bayesian optimization

first author · ACS Nano 2026

100sof thin-film samples fabricated and characterized per day

A robotic platform for mapping copolymer phase behavior

Hundreds of thin-film samples fabricated in hours, measured by synchrotron scattering, and turned into the first high-throughput map of the order–disorder transition landscape in triblock copolymer–homopolymer blends.

  • High-throughput experimentation
  • Robotics
  • SAXS / GISAXS

co-first author · Macromolecules 2026

6block copolymer chemistries in one generalizable model

Learning the processing–structure map

A machine learning framework that predicts block copolymer thin-film morphology from processing conditions, trained on high-throughput scattering data across six chemistries.

  • Machine learning
  • Structure–property relationships
  • Scattering analysis

An active-learning self-driving lab for polymer blend phase maps

Current work at Berkeley Lab — a multimodal self-driving lab that uses active learning to map polymer blend morphology and phase behavior, choosing each next sample where the map is least certain.

/ software

The tools

NOVA

The software that runs the lab. It drives the robots, starts each measurement, analyzes the data as it lands, and picks the next sample, with no one carrying things between instruments. New instruments plug in through adapters, so it isn't tied to one setup.

Author · in use at USM and Berkeley Lab · UR5, Opentrons, Sciprios, beamline DAQ · gpCAM, Bluesky, Tiled

polymermorphology.org

An open database of block copolymer thin-film structure, built from the robot's data across 6 chemistries, failed samples included. It's organized so machine-learning models can train on it.

Co-developer · open access
